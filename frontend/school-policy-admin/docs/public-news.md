# Public news page

The public `/news` page is a static editorial registry containing exactly nine source-linked entries. Each card shows only a source-derived headline, source attribution, and an outbound link to the original publisher. The application does not scrape pages at runtime, copy article bodies, or create internal article pages.

Source-hosted images are added only after their URLs are individually verified and approved for external use. Until then, cards use the neutral local fallback image. Remote source terms and availability must be reviewed before adding an image URL.
